# Rules of Engagement (RoE)

## Project
Website OWASP Top 10:2025 Security Assessment

## Assessment Purpose
To identify and document common web application security vulnerabilities in an authorized local lab environment.

## Target Application
Damn Vulnerable Web Application (DVWA)

## Testing Environment
Local lab environment only.

## Authorization
Testing is restricted to the locally hosted DVWA application controlled by the project owner.

## Testing Boundaries
- No testing of public websites or third-party systems.
- No attacks against systems outside the authorized lab.
- No destructive testing.
- No real user data will be accessed or collected.
- All findings must be supported by evidence.

## Assessment Methodology
OWASP Top 10:2025 categories will be reviewed individually.

## Evidence Handling
Screenshots, testing logs, and findings will be maintained for documentation.

## Reporting
Each finding will include its description, severity, evidence, impact, and remediation.

## Assessment Status
In Progress
