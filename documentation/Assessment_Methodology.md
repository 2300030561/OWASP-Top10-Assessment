# Assessment Methodology

## 1. Objective
Assess the security of the locally hosted DVWA application using the OWASP Top 10:2025 framework.

## 2. Assessment Approach

The assessment follows these phases:

### Phase 1: Preparation
- Identify the target application.
- Confirm the authorized testing environment.
- Define scope and testing boundaries.

### Phase 2: Information Gathering
- Identify application entry points.
- Review available application functionality.
- Observe HTTP requests and responses.

### Phase 3: Security Testing
- Review each OWASP Top 10:2025 category.
- Perform safe tests within the local DVWA lab.
- Record observations and test results.

### Phase 4: Evidence Collection
- Capture screenshots of relevant results.
- Maintain testing logs.
- Record the steps followed during testing.

### Phase 5: Risk Assessment
Each confirmed finding will include:
- Vulnerability description
- Severity
- Confidence
- Potential impact
- Supporting evidence

### Phase 6: Remediation
- Recommend security fixes.
- Explain how the vulnerability can be prevented.
- Retest after fixes where possible.

## 3. Severity Classification

| Severity | Description |
|---|---|
| Critical | Severe security impact |
| High | Significant security risk |
| Medium | Moderate security risk |
| Low | Limited security impact |
| Informational | Observation without a confirmed vulnerability |

## 4. Testing Principles
- Only authorized local testing is permitted.
- Avoid destructive activities.
- Do not report unverified vulnerabilities as confirmed.
- Mark incomplete tests as Not Tested.
