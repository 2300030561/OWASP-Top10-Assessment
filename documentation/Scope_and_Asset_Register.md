# Scope and Asset Register

## Project
Website OWASP Top 10:2025 Security Assessment

## Assessment Target

| Asset ID | Asset Name | Description | Environment |
|---|---|---|---|
| AS-01 | DVWA | Damn Vulnerable Web Application | Local Lab |
| AS-02 | Web Browser | Used to access DVWA | Local Machine |
| AS-03 | Testing Machine | Ubuntu WSL environment | Local Machine |

## In-Scope Assets
- Locally hosted DVWA application.
- DVWA login and authentication functionality.
- DVWA security testing modules.
- Local testing environment.

## Out-of-Scope Assets
- Public websites.
- Third-party applications.
- External servers.
- Systems without explicit authorization.

## Assessment Limitations
- Testing is restricted to the local DVWA lab.
- Only verified observations will be reported.
- Untested OWASP categories will remain marked as Not Tested.
